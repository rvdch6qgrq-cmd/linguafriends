# LinguaFriends — закрытая версия для друзей 🌍

Мобильное веб-приложение для небольшой компании (владелец + максимум 3 друга). Общение и языковая практика: личные чаты, голосовые сообщения, собственный словарик, карточки и обмен фразами, текстами и ссылками на мультфильмы.

## Где открывать
- [LinguaFriends — личные чаты и материалы](https://rvdch6qgrq-cmd.github.io/linguafriends/app/)
- [Старая демонстрационная версия](https://rvdch6qgrq-cmd.github.io/linguafriends/) — **не** отправляет сообщения между телефонами.

## Приватный режим
- В приложении **нет публичного каталога** незнакомых людей.
- Только подтверждённые по электронной почте и приглашённые участники могут читать/отправлять сообщения и материалы.
- Доступ проверяется на уровне Supabase RLS, а не только через скрытые кнопки.
- Владелец утверждается через свою почту в закрытом списке `app_private.allowed_emails`.
- Владелец может выпускать одноразовые 32-символьные приглашения для максимум трёх друзей. Каждое действует 14 дней.
- После активации приглашения друг автоматически попадает в личный чат с владельцем. Друг с другом можно соединиться по личному коду.
- Голосовые записи хранятся в приватном Supabase Storage; есть только доступ участникам чата. **Сквозное шифрование пока не предусмотрено.**

## Первоначальная настройка
1. Supabase: отдельный проект LinguaFriends, `jejpbaxwaeaqxfcnysae`. Основные таблицы и приватные политики уже развёрнуты.
2. Утвердить email владельца в `app_private.allowed_emails` (только на сервере, не в GitHub). **Нельзя** добавлять email или секретные ключи прямо в публичный репозиторий.
3. В [Authentication → URL Configuration](https://supabase.com/dashboard/project/jejpbaxwaeaqxfcnysae/auth/url-configuration) настроить Site URL и разрешённые redirects: `https://rvdch6qgrq-cmd.github.io/linguafriends/app/`. Это нужно для ссылок входа.
4. Для отправки письма на произвольные адреса друзей потребуется [настроить собственную SMTP-доставку](https://supabase.com/docs/guides/auth/auth-smtp), потому что стандартная Supabase-почта ограничена разрешёнными адресами команды.
5. Открыть приложение, войти по подтверждённому email. В разделе «Пригласить друга» владелец создаёт одноразовые коды и отправляет их знакомым.
6. Друзья входят по email и активируют код приглашения.

## Исходники
`webapp/src/` — React-клиент. `webapp/supabase/` — исходные SQL-файлы MVP. `app/` — автоматически собранная публикация GitHub Pages. CI: `.github/workflows/publish-app.yml` и `diagnose-browser.yml`.

**Пока не проведён приёмочный тест двух реальных пользователей на разных телефонах.** Прежде чем считать проект готовым к постоянному использованию, проверьте регистрацию, вход, обмен текстом и голосовыми, восстановление сессии и доступ с другого аккаунта.
