# LinguaFriends 🌍

Мобильная веб-демоверсия приложения для языкового обмена.

## Что уже есть

- Удобный интерфейс для iPhone и Android.
- Демонстрационные личные чаты, текстовые и голосовые сообщения.
- Поиск языковых партнёров, имитация заявок на знакомство.
- Личный словарик, карточки для повторения фраз.
- Добавление на главный экран телефона (PWA).

**Важно:** сейчас это **демо**. Собеседники вымышленные, сообщения остаются в браузере на текущем устройстве. Голосовые в деморежиме не передаются в интернет. Для реального общения между двумя людьми нужно подключить регистрацию, базу данных и защищённое хранилище аудио. Автоматического перевода и расшифровки речи пока нет.

## Как открыть на iPhone

1. В GitHub открой **Settings → Pages**.
2. В **Build and deployment → Source** выбери **Deploy from a branch**.
3. В разделе **Branch** выбери **main** и **/(root)**, затем **Save**.
4. После успешной публикации адрес сайта: `https://rvdch6qgrq-cmd.github.io/linguafriends/`.
5. Открой адрес в Safari → «Поделиться» → «На экран „Домой“».

Не скачивай ZIP: все файлы находятся прямо в GitHub.

## Технические детали

- `index.html` — самостоятельная демонстрационная версия.
- `manifest.webmanifest` — настройки мобильного веб-приложения.
- `icon.svg` — иконка.
- `sw.js` — автономная оболочка для открытия ранее посещённого интерфейса без сети. Онлайн-переписка при отсутствии сети не работает.
