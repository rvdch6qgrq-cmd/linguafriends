# Подключение реального общения в LinguaFriends

## Что уже сделано
- Демо: https://rvdch6qgrq-cmd.github.io/linguafriends/
- Полная мобильная версия: https://rvdch6qgrq-cmd.github.io/linguafriends/app/
- React-код: webapp/src/
- SQL-схема: webapp/supabase/schema.sql, discovery.sql, materials.sql
- Автосборка: .github/workflows/publish-app.yml

## Что нужно для работы между двумя телефонами
1. Создай проект Supabase (или подключи приложение Supabase в ChatGPT, чтобы я могла помочь настроить проект напрямую).
2. В новом пустом проекте последовательно выполни SQL из:
   - webapp/supabase/schema.sql
   - webapp/supabase/discovery.sql
   - webapp/supabase/materials.sql
3. В Supabase → Authentication → URL Configuration установи Site URL:
   https://rvdch6qgrq-cmd.github.io/linguafriends/app/
   И добавь этот же URL в Redirect URLs (при необходимости с завершающим /**).
4. В GitHub → репозиторий → Settings → Secrets and variables → Actions → Repository secrets
   добавь:
   - VITE_SUPABASE_URL = Project URL из Supabase
   - VITE_SUPABASE_PUBLISHABLE_KEY = public publishable key из Supabase (sb_publishable_... или legacy anon key)
   Это **публичные клиентские настройки**, они окажутся в JS-бандле после сборки.
   **Не добавляй** service_role, secret key, пароли или токены администратора.
5. В GitHub → Actions → Publish LinguaFriends app → Run workflow запусти пересборку.
6. После публикации открой мобильную ссылку на двух устройствах, войди по email и добавь друга по коду приглашения.
7. Открой «От друзей», выбери друга, отправь фразу или текст, затем проверь доставку на втором устройстве.
8. Проверь запись/воспроизведение аудио на iPhone и Android, а также ограничения доступа: третье лицо не должно видеть материалы чужого чата.

## Важно
- GitHub Pages хранит только публичные файлы интерфейса. Личные сообщения и аудио хранятся в Supabase, защищаются RLS, но не имеют сквозного шифрования.
- Функция поиска новых людей требует отдельной модерации, обработки жалоб, удаления аккаунта и защиты от спама перед публичным запуском.
- Файлы голосовых до 8 МБ, запись материала ограничена 60 сек.
- Перевод открывает внешний Google Translate. Автоматическая расшифровка аудио пока отсутствует.
- Демонстрационные записи и материалы не отправляются реальным людям.
